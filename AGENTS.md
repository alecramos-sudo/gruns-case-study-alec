# Project rules

## Git

- Never commit until Alec approves the complete staged diff and exact commit message.
- Push only approved commits. A changed staged diff needs new approval.

## AI transparency

Keep `.ai/AI_PROCESS.md` current as the public development record.

- Summarize goals, decisions, review findings, cuts, and verification by work stage.
- Do not publish exact prompts, session IDs, interview preparation, credentials, environment data, customer data, or hidden reasoning.
- Record model and cost information only when it is verifiable. Use `Unavailable` instead of estimating coding-harness spend.
- Show Alec the complete staged diff and exact commit message before committing.
